# /pdf2zh：轻量化学术 PDF 英转中

原则：**提取用脚本，翻译由当前会话模型直接完成**（本地模型，无需额外 API key、无需装新依赖）。零外部服务。

## 输入

- PDF 路径（必需）
- 可选参数（用户口头给出即可，不必严格按 `--` 格式）：
  - 页码范围（如“只翻前 5 页”“1-8 页”）
  - `中英对照`：额外产出逐段对照版
  - `含附录`：默认只翻正文（Abstract→Conclusion），附录用户点名才翻

## 流程

### 1. 提取（脚本，已处理双栏）

```bash
python3 ~/.dsh/skills/pdf2zh/extract.py <pdf> [--pages 1-8]
```

输出 `<同目录>/<stem>.txt`，带 `[PAGE n]` 标记。**提取后必须抽查**：读前 1-2 页文本，若乱序/公式严重残缺/明显乱码，先向用户报告并询问（可改用 arXiv 源码 .tex，用户能提供 .tex 时直接翻 .tex，效果更干净）。

### 2. 通读并定位结构

读完整份提取文本（一般 5-15k token，一次读完），定位：标题 / 作者 / 会议 / 摘要 / 各编号章节 / 图表标题 / 参考文献 / 附录。
**跳过封面页**：从 ResearchGate/Scilit 等网站下载的 PDF 第一页常是站点封面（"See discussions, stats..."、"Article in ..."、"CITATIONS/READS" 等字样），这不是论文内容，直接跳过，从出现真正标题+摘要的那页开始。

### 3. 逐节翻译，写入 `<stem>.zh.md`

**输出目录**：若任务说明里指定了保存目录（如插件面板设置的「保存路径」），`.zh.md`、`.en-zh.md` 与提取的 `.txt` 全部写入该目录；未指定时写到源 PDF 同目录。

第一节约束用 `write` 建文件，后续节用 `edit` 追加。逐节完成，不要试图一次生成全文。

**翻译纪律（铁律）：**
1. **公式不翻译**：LaTeX/公式符号原样保留，公式后的文字解释正常翻译；
2. **图、表内容一律不动**：图内的任何文字（流程图标注、图例、坐标轴刻度、子图标题）
   与表格内的任何单元格内容，**既不翻译也不搬进正文**。正文里只在原位置写一句
   `（图 N：…）`/`（表 N：见原文）` 占位说明即可；绝不把图内文字改写成中文句子。
   若提取文本里出现成串的图内标签（如 `Prompt Encoder`、`Refined Masks`、`Road`），
   说明提取器把图形区域当成了正文 —— 必须丢弃这些片段，不要翻译它们。
3. **参考文献不翻译**：文末只写 `> 参考文献（References）未翻译，见原文。`；
4. **专名保留原文**：模型名（SAM、UNet、ViT、Swin…）、数据集名（Pavia University、Houston 2013…）、指标（mIoU、OA）、引用编号 [12]、代码/DOI 链接，一律保留英文；
5. **数字、单位、超参数原样**（82.3%、4×4 patch、1e-4）；
6. **不编造**：提取不到的内容（纯图片内容等）只标注 `（图：…）` 占位，绝不脑补图内文字；
7. **不重复**：不要把同一段文字翻译两遍（提取器可能把同一段切成多块），成段重复时只保留一份。
8. **文体**：学术书面中文，长句按中文习惯断句；摘要要像摘要，不要口语化。

**各部分处理：**
- 标题：翻译，原文附在括号里；作者/机构/会议名保留原文；
- 章节号保留（`## 3. Method` → `## 3. 方法`）；
- 图表标题（caption）：可翻译，保留 `Figure 3:` / `Table 2:` 前缀（写 `图 3:` / `表 2:`）；
  **caption 不是图内文字** —— 图内（图形框线之内）的文字仍然完全不翻；
- 表头与单元格：不翻译、不重排，正文中不要复述表格内容；
- 代码/伪代码块：代码不翻，注释可翻。

### 4. 术语一致性

翻译每一节前，先查 `~/.dsh/skills/pdf2zh/glossary.md`；全部完成后，把本文新出现的**核心术语**（反复出现的领域专有词）补进术语表（`英文: 中文` 一行一个，只收值得固定的词）。

### 5. 中英对照（用户要求时）

额外产出 `<stem>.en-zh.md`：每个英文自然段后紧跟 `> ` 开头的中文对应段，逐段对齐（摘要/正文逐段，公式段原样+`>` 中文解释）。

### 6. 汇报

结束时报告：
- 输出文件路径（`.zh.md`，以及 `.en-zh.md` 若有）
- 覆盖范围（翻了几页/哪些节，附录是否未翻）
- 本次新增的术语表条目

## 与插件管线的分工

上面的流程是**会话内 Markdown 翻译**（产出 `.zh.md`，适合快速通读）。
需要在**原 PDF 版面上**得到排版保真的中文版时，走插件面板的「一键翻译」：
宿主会启动 `pipeline/run_pipeline.py`（提取 → 并发翻译 → 就地渲染），产出 `<原名>.zh.pdf`。
pdf2zh v0.13 管线对图/表/公式的口径与本技能的「翻译纪律」一致，且是**几何强制**的：

- **图、表**：区域内的文字不提取、不翻译、不擦除、不回填，原位矢量/位图零改动；
- **独立公式**：不提取、不翻译，原矢量字形留在原位置，并登记为保护区，正文排版绕开它；
- **行内公式**：还原为 Unicode 文本交模型修复（禁一切 LaTeX 标记，上下标用 `_{}`/`^{}`），
  按真实上下标排回正文，**不再裁剪贴图**；
- **绝不叠印**：放不下的段落原样保留英文（不擦白、不覆盖），绝不在公式/图上压字。

## 边界情况

- **>12 页**：默认正文到 Conclusion 为止，明确告知用户附录未翻，按需补；
- **扫描版 PDF**（提取出来是空/乱码）：告知用户此 PDF 无文本层，需 OCR 或提供 .tex，不要硬翻；
- **arXiv 论文**：若用户给 arXiv ID 而非 PDF，可先用 `arxiv` skill 下载 PDF 再走本流程；若用户能拿到 .tex 源码，优先翻 .tex；
- **翻译语言**：默认中译英→中；用户要其他方向（如日→中）同样适用，术语表按需扩展。
